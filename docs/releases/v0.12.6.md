# Winglet v0.12.6

A small release with one fix: the pet stays in place.

## The pet no longer jumps up and down

The pet sits on the message box at the bottom of a chat. It was positioned from the top of everything stacked above the bottom of the screen, which includes the "Working on your request" card, the Steer / Queue / Interrupt chips, the command list and the offline note. Each of those appears and disappears while a turn runs, and the pet jumped each time.

The pet is now positioned from the message box and the padding under it only, so those extras no longer move it. It still follows the box when the box itself grows, for example when you type several lines or attach a file.

This was found from screenshots and by reading the code; it has not been tried on a phone yet, so treat it as a likely fix. Two new tests cover it, and one of them fails if the old positioning comes back.

## Not covered

Nothing else changed. Chat names for chats that start with "Continue our chat…" or with an image can still be poor; that comes from Hermes's own title code.
