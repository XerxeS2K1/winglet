# Winglet v0.10.1

The first release of this maintained fork. The original project stopped maintenance on 5 November 2026. This fork keeps Winglet working with current Hermes Agent (tested on v0.22.7 and against Hermes `main` every week) and fixes the bot problems that Hermes updates exposed.

**Moving from the original Winglet:** this release is signed with the fork's own key, so Android will not update the original app over it. Uninstall the old app once, install this one, and pair again. After that, updates arrive inside the app.

- **A second bot now works in the app.** Winglet serves each bot through Hermes's own per-profile adapters. Before, a bot such as "Research" showed a runtime error. A new bot is switched on for Winglet when you create it.
- **Bots can ask each other for help.** `ask_bot` uses Hermes's live delivery (needs Hermes v0.22.5 or later). The chat shows a short "Asked <bot>" line you can tap to see the question and answer. The Bots screen tells you if your Hermes is too old for this.
- **Switch bots from the chat header.** Tap the bot's face at the top of a chat (with two or more bots).
- **`/yolo` and `/approvals` now need a signed request**, like `/approve`. A login token alone can no longer switch approvals off. The app signs them and never queues them while offline.
- **Clearer bot states.** A bot Hermes has not started shows "Not running" instead of failing silently, and an unreadable bot list is treated as unknown, never as empty.
- **Fewer lost replies.** A reply cut off by a restart is closed off cleanly when the server comes back.
- **Updates come from this fork.** The in-app updater reads this fork's releases. The README, setup guide and install command now point here.
- **Tested against Hermes.** CI runs the full suite on every push against pinned Hermes v0.22.7, and weekly against Hermes `main`. See [Hermes compatibility](../HERMES_COMPATIBILITY.md).

This is a personal fork shared as-is, with no promise of support. Issues and pull requests are welcome.
