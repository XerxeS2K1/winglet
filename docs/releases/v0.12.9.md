# Winglet v0.12.9

A small release with one fix: the pet no longer covers the "While it works" row.

## Pet and the row above the message box

The pet stands on the top edge of the message box. While a turn runs, the "While it works: Steer / Queue next / Interrupt" row sits right above the box, and the pet covered its label. When a pet is perched, that row and the offline note now start 52 px in from the left, clear of the pet. The pet itself does not move, and the rows go back to the left edge when no pet is showing.

The task card and the command list still reach the left edge, so the pet can stand over a little of them. This has not been seen on a phone yet; the 52 px comes from the pet's size and position. After updating, start a message while a turn is running and check the label is readable.

## Not covered

Moving the "Plugin tests with Hermes" CI job to Hermes v0.23.4 fails in 17 tests that were written against older Hermes internals; that is parked in its own pull request. The server plugin is unchanged apart from its version number.
