# Winglet v0.10.6

Completes the in-app server plugin update: the app now offers it, with a fresh fingerprint check and a version the server verifies.

- **Server plugin updates from the app.** When the server's plugin is behind the latest release, the app offers "Update server too?" with Update, Later and Skip this version. Only the owner device can trigger it, and it asks for a fingerprint or PIN first. The request names the exact version and carries an idempotency key, so a retry after a dropped reply returns the same job instead of starting a second. The server installs the release by its commit SHA, makes a backup first, and rolls back automatically if the new version does not start. A failed update never restarts the gateway.
- **Update requests are gated on screen focus.** A request started while the Server screen is open is dropped if the screen loses focus during the unlock, so a backgrounded app cannot update the server.
- **Unknown roles are no longer treated as owners.** A device whose role is missing or unrecognised cannot trigger a server update.
- **The prompt stays out of the way.** It does not appear on the pair or QR scan screens, and the Server screen's Update button sends the version the server expects instead of nothing.

The server plugin is on the same version. Hermes 0.23.0 is the supported server version.
