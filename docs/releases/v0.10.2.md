# Winglet v0.10.2

Fixes for voice, bots and the model label, plus a second pet gallery. Tested by the maintainer's automated checks (app type check and tests, plugin tests with and without Hermes). The voice fixes and the new bot screens have not yet been tried on a phone, so treat this as a release for early adopters.

- **Hands-free voice no longer fails with "undefined is not a function".** React Native's `AbortSignal` has no `throwIfAborted`, and the voice code called it after every recording. It now uses a small helper.
- **Hold-to-talk no longer cancels itself.** It asked Android for the microphone permission on every hold, which pauses the app even when granted. It now checks first and asks only when the permission is missing. The very first permission prompt still ends that one hold; hold again after allowing.
- **The model label shows the model that is actually answering,** including a fallback model, not the configured default.
- **New bots start without restarting the gateway.** After a bot is created and Winglet is switched on in it, the running gateway is asked to look again.
- **Bot hand-offs are easier to follow.** A busy bot shows "Working" and how many jobs are queued behind it (owner only). A hand-off shows which Winglet chat asked, immediately, and a short "finished" note appears when it is done without waking the asking bot. An owner-only queue sheet shows the order of waiting jobs.
- **Persona edits** now say they apply to new chats, not to hand-offs already running.
- **Pets: a second gallery source,** codex-pets.net, alongside Petdex.
- README screenshots refreshed and the licence file names the fork maintainer.

The bundled web portal was not rebuilt for this release, so web-only changes arrive in the next one.
