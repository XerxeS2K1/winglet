# Winglet v0.10.7

Repairs the server-plugin update path and makes an in-flight update's progress and result survive a closed app, a dropped connection and a relaunch. Adds one-step device linking and trusted-phone browser sign-in.

- **The server updater now consents to declared Python dependencies.** The plugin's installer passes Hermes's `--yes-deps` flag, so a phone-triggered update is no longer refused at the dependency step. A signed owner request is still the authority; the repository and commit stay server-controlled.
- **Update progress cannot be dismissed.** While a job runs, the progress sheet ignores the backdrop, back button, escape and swipe-to-dismiss. The result stays on screen until you acknowledge it explicitly.
- **Recovery survives reconnect and relaunch.** Progress and results are kept per server and restored on reconnect or app restart. An unconfirmed request keeps its durable "unknown result" state, and an old finished job can no longer clear a newer pending intent. A lost POST reply no longer strands the request.
- **Owner authority is re-checked before the job is created.** The server validates the owner device, its verified state and its signing key both before and after the asynchronous release lookup, closing a window where a demoted or rotated device could still start an update.
- **Timeout and cancellation clean up the installer's children.** The installer runs in its own process group and the updater stops the whole tree on timeout or cancel, so a killed install cannot leave a writer behind for the rollback.
- **Only the requested version counts as success.** Reconciliation requires the running version to equal the requested target; an unrelated version is reported as a failure, and a restart is requested only when the update is still the one that was asked for.
- **One-step device linking.** A new device pairs by scanning a QR code or entering a short code, with a verified signing key, instead of the older multi-step flow.
- **Trusted-phone browser sign-in.** A phone already signed in can authorise a browser session, subject to owner approval.

The server plugin is on the same version. Hermes 0.22.7 and 0.23.0 are the supported server versions.

> **Upgrade note.** The live 0.10.5 plugin and the published 0.10.6 updater both omit `--yes-deps`,
> so neither can install this release by itself. A one-time manual install of this release's plugin
> is required first; see [SERVER_PLUGIN_UPDATE.md](../SERVER_PLUGIN_UPDATE.md).
