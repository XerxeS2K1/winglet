# Winglet v0.12.5

A small release with one fix: chats now get their automatic name more reliably.

## Chat names: no more chats stuck on "New chat"

Hermes writes a short title for each chat from its first message. Winglet copied that title across by checking every 1.5 seconds, but it gave up after 45 seconds. A first turn that was slow, for example one with approval prompts and several tool calls, could finish its title after that window, and the chat stayed as "New chat" even though Hermes had named it.

Winglet now checks quickly for 45 seconds, then every 5 seconds for up to 10 minutes, and looks once more when a turn finishes. It stops as soon as the model's title arrives or you rename the chat yourself.

This was found by reading the code and the stored data for one chat; I could not reproduce the failure on a phone, so treat it as a likely fix, not a proven one. Three new tests cover it.

## Not covered

- Titles for chats that start with "Continue our chat…" or with an image can still be poor or long. That comes from Hermes's own title code, not Winglet.
- This release changes the Winglet plugin only; the app is unchanged apart from the version number.
