# Winglet v0.10.10

Two fixes for things the owner hit on the phone: an update that looked broken while it was working, and a fallback strip whose countdown could not be trusted.

- **An update survives the restart it causes.** Installing the server plugin restarts the Hermes gateway, so for about half a minute whatever fronts it answers 502. The app used to take that as a failure and show "Server returned 502" for the update you had just asked for. Reads now ride through a 502, 503 or 504 with three attempts and a short backoff, and the screen says the server is restarting instead of erroring. After 90 seconds of silence it does report a real error, so a server that is genuinely down still tells you.
- **Writes are never retried.** Only reads retry. A job is created once, and its idempotency key owns what happens next, so an update cannot be started twice by a retry.
- **The plugin button waits instead of failing.** A 502 on the start of a plugin install is treated as a restart in progress, and the follow-up refresh is retried until the server answers, rather than failing the install you just tapped.
- **The fallback countdown no longer restarts.** The server sent only "retry in N seconds", and the phone anchored that to the moment the answer arrived. Every refetch (a new reply, a chat switch, opening the model sheet) restarted the clock, so the strip ran ahead of the real deadline. The server now sends an absolute reset time as well, the strip believes whichever reading is shorter — the relative count is safe against a wrong phone clock, the absolute deadline is safe against a refetch — and a refresh can never push the deadline out.
- **The strip stops saying "next message".** With no cooldown there is no timer, and pairing an empty timer with a reason you cannot act on read as noise. The right-hand text is now empty in that case, and the second line says what actually happens: which model is in use, and that the main one is tried again when you send. That line now shows with the keyboard up too, which is when it was being clipped.

The server plugin is on the same version. Hermes 0.22.7 and 0.23.0 are the supported server versions.

> **Upgrade note.** v0.10.9 can install this release by itself, so no manual step is needed. If you are still on 0.10.5, install the 0.10.8 plugin manually once first; see [SERVER_PLUGIN_UPDATE.md](../SERVER_PLUGIN_UPDATE.md).
