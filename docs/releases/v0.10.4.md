# Winglet v0.10.4

Reconnect fixes for after the phone has been asleep, a one-time battery question, and compatibility with Hermes 0.23. Tested by the maintainer's automated checks (app type check and tests, plugin tests with and without Hermes, a release build that compiled the new Android code) and a separate read-only code review. None of the changes below has been tried on a phone yet, so treat this as a release for early adopters. No server plugin update is needed for the app fixes; the plugin is updated only to carry the Hermes 0.23 declaration.

- **No more false "No internet" after sleep.** Android can report its connection as unchecked for a while after deep sleep even though it works, and the app believed it. It now counts as offline only when Android reports no connection at all, asks the phone again every 3 seconds while it thinks it is offline and as soon as you open the app, and never shows "No internet" while its own connection to the server is open.
- **"No internet" has a "Try now" button,** and the "Details" link no longer appears on the Connection screen, where it only opened the screen you were already on.
- **"Signed out" needs proof.** One rejected check after sleep used to stop the app retrying until you restarted it. It now checks the pairing a few more times, a few seconds apart, and only shows "Signed out" if every check is rejected. Reopening the app or tapping "Try now" while signed out looks again and reconnects if the pairing is fine. A phone that really was unpaired takes about 7 seconds longer to show "Signed out".
- **One-time battery question.** About 5 seconds after Winglet opens (once paired and unlocked), it explains in a sentence and, if you continue, opens Android's own dialog to leave Winglet out of battery limits. It asks once and never again, whatever you answer. Android never lets an app switch this off by itself. There is no Settings row to ask again.
- **Hermes 0.23 compatibility.** The plugin declares `requires_hermes >= 0.22.7`, and a test that stood in for a removed Hermes function was updated. No change in behaviour on Hermes 0.22.7.
