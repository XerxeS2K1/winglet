# Winglet 0.12.0

The menus and the words on them, plus fourteen plugin fixes from a full read of the plugin.

## The menus

- **One Server screen.** Status, updates and devices now sit on one screen instead of three, and the version footnote that duplicated the update row is gone. A per-bot "your bots" card and its warnings are gone from About.
- **Settings regrouped** into Preferences, On this phone and App. Notifications sit under Preferences; "Open the app on" and About are last.
- **Fewer duplicate entries**, so the same screen is not reachable by two names in two places.
- **A wording pass, 15 findings**: Bot tab and Add bot, Save routine, Model, All chats, Bots, Delete bot, Cancel sign-in, Copy diagnostics, Connect a browser, Chats rather than Conversations, and the push settings say push service, delivery and message in the normal UI while the jargon stays inside diagnostics.
- **The fallback strip reads like a person wrote it**: "Claude can be used again in 1 h 13 min" instead of "Claude is tried again in 1 h 13 min".

## Reports

The routine-results feed is called **Reports** everywhere: in the app, in the plugin's own messages, and in `/api/chats` and the event stream. Stored titles and chat ids are untouched, so nothing needs migrating.

## Plugin fixes

From three passes of a full review (#16 #17 #18 #25 #26 #29 #32 #34 and six more):

- A pause switch that is missing reports unavailable instead of a 500.
- A renamed keyword turn no longer returns a 500.
- An entry with no start time no longer counts a later process.
- A spoken reply is off the event loop and is dropped when the turn is stopped.
- A cancelled transcription releases its session.
- The Rooms project snapshot is off the event loop.
- Routine history writes only the runs that changed.
- The tunnel readiness check has a total deadline.
- The role re-check reads a fresh pairing row rather than a cached one, so a turn is never decided on stale data.

## Usage

Token and cost figures are in pounds by default, with a £ / $ choice, and the screen shows tokens and cost per hour.

## Upgrading

The plugin and app both update themselves; nothing to do by hand. Android needs the same signing key as before, so this installs straight over 0.11.5.
