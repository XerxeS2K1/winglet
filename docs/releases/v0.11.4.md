# Winglet v0.11.4

One bug, with an outsized effect on anyone with more than one bot.

- **Pairing a browser signed the other bots out.** Each bot on a server is its own entry holding its own copy of the token. Pairing again issues a new token and device id and replaces the server's entry, but the new token was never passed to that server's other bots — they kept one belonging to a device that no longer existed, every request came back 401, and the app's own rule turned that into "Signed out". A re-pair now hands the new token, device id and key to the server's bots and reconnects them.
- Everything else is v0.11.3: the browser sign-in QR shows on `/pair` even when a server is already saved, "Complete verification" offers the one-scan path, and the self-updater follows GitHub's release-asset redirect.

The server plugin is on the same version. Hermes 0.22.7 and 0.23.0 are the supported server versions.
