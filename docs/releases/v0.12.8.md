# Winglet v0.12.8

A small release with one fix: branching works again on current Hermes.

## Branch, regenerate and edit-and-rewind

Branching a chat, regenerating a reply and editing an earlier message all read and write Hermes's saved conversations. Hermes 0.23 moved where it keeps those, so on that version Winglet could not reach them and would have refused with "This Hermes can't reach its session database". Winglet now uses Hermes's new storage interface, and still uses the old route on older Hermes.

A new test runs the real branching code against the real Hermes session store: it reads a chat, builds a branch from part of it, routes the new chat, and rewinds the latest turn in place while the original stays intact. The older safety test that refuses to rewind a newer exchange now runs on the new interface too.

This has not been tried on a phone yet. After updating, try Branch on a chat, then regenerate a reply, and tell me if either is refused.

## Not covered

The repository's "with Hermes" CI job is still pinned to an older Hermes, so it skips the new test. The server plugin updates together with the app.
