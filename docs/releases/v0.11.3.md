# Winglet v0.11.3

Signing a browser into Winglet, in one scan.

- **The QR was hidden from anyone who already had a server saved.** On `/pair` it only appeared when the app had no servers at load, so every returning user got just "paste a pairing link" or "address and code".
- **"Limited connection" no longer sends you round in a circle.** A code alone connects with limited access — the key was looked up over the network, so it cannot verify the server. "Complete verification" used to drop you back on the form to find another code. On the web it now shows the QR right there: one scan from your owner phone and the browser is verified.
- **Self-update could not download a release at all.** GitHub redirects a release download to its asset CDN, and only two hostnames were followed. GitHub has moved to `release-assets.githubusercontent.com`, so every check found the release and then refused the asset. Fixed; the digest is still checked against what GitHub publishes.

The server plugin is on the same version. Hermes 0.22.7 and 0.23.0 are the supported server versions.
