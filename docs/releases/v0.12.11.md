# Winglet v0.12.11

A maintenance release that updates Expo from 57.0.31 to 57.0.34 to clear dependency advisories found by a code scan.

## What changed

Two high-rated advisories (in `@expo/cli` and `zod`, which only run while building the app) and the moderate ones in `node-forge`, `glob` and the `@expo/config` packages are gone. React and React Native are unchanged. Four small Expo runtime packages move by patch versions: `expo`, `expo-asset`, `expo-constants` and `expo-modules-core`. Winglet's own code does not use any of the affected packages, and none of them was running on your phone, so this is about build safety, not a flaw seen in the app.

## What is still open

Four moderate advisories remain, all through `minimatch` 10.2.6 pinned by Expo's `@expo/fingerprint`, a build-time tool. They allow a slow match on crafted file patterns while building. The only automatic fix on offer is to go back to Expo 52, which I did not take. They clear when Expo updates that tool.

The scan's other nine findings are still not fixed. The app is rebuilt with the newer Expo, and it has not been tried on a phone. The app and the server plugin update together through the in-app Update.
