# Winglet v0.11.2

The first release the server could update itself to — and the one that made that possible.

- **Self-update would have refused every release.** GitHub answers a release download with a redirect to its asset CDN, and the download only followed redirects to the two hostnames it knew. GitHub had moved to a third (`release-assets.githubusercontent.com`), so every check ended in *"the plugin asset could not be read: redirect outside XerxeS2K1/winglet refused"* while the release itself was found and looked fine. The CDN host is allowed now; the release metadata still may not come from it, and the SHA-256 still has to match what GitHub publishes before anything is installed.
- Everything else is v0.11.1: the app's update sheet compares the installed binary rather than the JS bundle, and the server updates its own plugin when idle, digest-checked and same-major.

The server plugin is on the same version. Hermes 0.22.7 and 0.23.0 are the supported server versions.
