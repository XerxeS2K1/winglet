# Winglet v0.11.0

The server now updates itself. The app goes back to being just an app.

This is a bigger change than a version number usually means, so here is exactly what moved and what
still needs your hand.

## The server updates the server

The Winglet plugin checks GitHub after it starts and every six hours. When a newer release exists it
updates itself and restarts, with nobody tapping anything. It only does so when every one of these is
true:

- auto-update is on (it is by default, and it is a switch in the app's About screen for owners);
- the release is newer than the running version;
- the release is the **same major and minor** — so while Winglet is on 0.x, a 0.11 → 0.12 change
  needs your tap, because that is where the app/server contract can break;
- no chat is replying and no job is running;
- the plugin asset's SHA-256 matches the digest GitHub publishes for it, and the installed files
  match those bytes afterwards;
- the zip's own version equals the release tag, and its required Hermes version is satisfied;
- it has not already failed on this release.

A failure before anything is installed is retried twice after thirty minutes. A release that installs
and then does not survive is never retried — the version is marked bad and stays bad until something
newer appears.

## Nothing gets stranded

Before the files change, the update writes a marker. If the new version never reports that it is
serving, a systemd watchdog — outside the plugin, so it still works when the plugin cannot import —
restores the previous version and its database, restarts, and writes an audit entry. `hermes winglet
rollback` does the same thing by hand. It refuses to restore a database while a gateway is running.

## The app only updates the app

The update sheet is now a download and an Android install. The owner-consent text, the job stages,
the restart notices and the recovery paths are gone, because the phone no longer sends a server
update it cannot survive. The Server screen's duplicate button is gone with them.

The app still shows what the server is running and when it last updated.

## What still needs you

- A major change (0.x → 0.y while we are on 0.x) is manual: the app offers it, the server will not
  take it on its own.
- Hermes itself is never updated automatically.

## Upgrading

v0.10.11 can install this release by itself. If you are on 0.10.5 or older, install the 0.10.8 plugin
manually once first; see [SERVER_PLUGIN_UPDATE.md](../SERVER_PLUGIN_UPDATE.md).
