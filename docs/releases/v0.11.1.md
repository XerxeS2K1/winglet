# Winglet v0.11.1

A one-line bug with an outsized effect: the app could refuse to install itself.

- **The update sheet compared the wrong version.** It asked the JS bundle what version the app was, and on Android the bundle can be the one the server serves — which is newer than the installed APK. So a phone running an older app was told it was already on the new release, and the install button did nothing. It now compares the version of the installed binary, which cannot be outrun by a server.
- Everything else is v0.11.0: the server updates its own plugin when a release is newer, idle-safe, digest-checked and same-major; the app just downloads and installs.

The server plugin is on the same version. Hermes 0.22.7 and 0.23.0 are the supported server versions.
