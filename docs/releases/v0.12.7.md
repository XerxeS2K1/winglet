# Winglet v0.12.7

A small release with one fix: new chats get named again.

## New chats get their name

Hermes names each chat itself, and Winglet copies that name into the chat list. Hermes 0.23.4 moved where it keeps those names, so Winglet could no longer find them and left every new chat as "New chat". Winglet now reads the name from Hermes's new location, and still falls back to the old one on older Hermes.

0.12.5 also lengthened how long Winglet keeps watching for the name; that stays, but it could not help on its own, because the name was being looked up in the wrong place.

This was found from the logs and the Hermes source, and a new test covers it. It has not been tried on a phone yet, so after updating, start a new chat and check that it gets a name.

## Not covered

Chats that begin with "Continue our chat…" or an image can still get poor names; that comes from Hermes's own title code. The server plugin updates together with the app.
