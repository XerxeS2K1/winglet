# Winglet v0.11.5

Two changes you can feel, and the first batch of the code review.

- **A message typed on the home screen starts a new chat.** It used to append to your main chat. Now it opens a fresh chat, carries the text, attachments and any reply target into it, and never touches the home chat. A draft survives leaving the screen; if the server cannot start a chat, the text stays put and it says so instead of losing it.
- **Long messages are refused, not cut.** Over 16,000 characters used to be sliced and the tail lost. The server now rejects it with the real length and the limit, and the composer stops at the same number.
- **Batch one of the review, eight security and data-loss fixes.** The bearer token is no longer accepted from a query string; a body that is not a JSON object is a 400 instead of silently becoming "off"; an attachment that cannot be prepared now blocks the send instead of vanishing; deleting a message or a chat takes its files, storage budget and live URL with it; agent media is swept after 30 days and its links expire; a failed hand-off or approval card is no longer reported as delivered; a routine edit can no longer blank its name.

The server plugin is on the same version. Hermes 0.22.7 and 0.23.0 are the supported server versions.
